# Haida Makouangou Portfolio

A modern, responsive portfolio built with React, Vite, TypeScript, Tailwind CSS, Motion, React Icons, and EmailJS.

## Run locally

```bash
npm install
npm run dev
```

## Before publishing

1. Add your headshot as `public/profile.jpg`.
2. Add your resume as `public/resume.pdf`.
3. Update project links in `src/data/projects.ts`.
4. Update your GitHub, LinkedIn, email, and written content.
5. Configure EmailJS and create a `.env` file from `.env.example`.

## Build

```bash
npm run build
```

## Netlify

Build command:

```text
npm run build
```

Publish directory:

dist
