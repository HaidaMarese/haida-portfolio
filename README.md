# Haida Makouangou Portfolio

A modern, responsive personal portfolio showcasing my software engineering, full-stack development, AI/ML projects, professional experience, technical skills, and certifications.

## Technologies Used

- React
- Vite
- TypeScript
- Tailwind CSS
- Motion
- React Icons
- EmailJS

## Run Locally

Clone the repository:

```bash
git clone https://github.com/HaidaMarese/haida-portfolio.git
```

Open the project folder:

```bash
cd haida-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Setup

- Add the profile photo as `public/profile.jpg`.
- Add the resume as `public/resume.pdf`.
- Update projects in `src/data/projects.ts`.
- Update technical skills in `src/data/skills.ts`.
- Configure EmailJS using a `.env` file based on `.env.example`.

## Deployment

### Vercel

- Build command: `npm run build`
- Output directory: `dist`

### Netlify

- Build command: `npm run build`
- Publish directory: `dist`
